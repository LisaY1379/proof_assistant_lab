THE PRIORITY RULE

Basic first. Observe when blocked.

Use direct definitions, calculations, and logic as far as they address the current goal. When they leave a gap, identify a relationship that suggests a new target. Verify the reduction, then return to basic steps. Repeat if another gap remains.

“Stuck” is local to the current representation and allowed basic moves. It does not mean the theorem is unprovable. The observation proposes a route; verification establishes that it works.

Read the finished proof

Since a and b are even, write a = 2m and b = 2n for integers m,n. Then a + b = 2m + 2n = 2(m + n). Since m + n is an integer, a + b is even. □

The short proof compresses the choice of a useful representation. The graph exposes that choice and its motivation.

Three node types, two directions

Fact: an assumption or a verified statement, with its domain and dependencies.

Goal: a statement still needed; it closes when verified facts establish it.

Observation: an explicit match between a feature we have and a feature we need. It suggests a move but is not a proof edge.

The forward graph records deductions. The backward graph records sufficient obligations. Direction and node type are separate: basic steps can occur in either graph.
