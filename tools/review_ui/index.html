Proof Strategy Extraction UI

0. Dataset

RealAnalysis uses the Lean-to-English workflow. HighDimensionalStatistics loads the PDF-aligned book proof library.

1. Views

These buttons switch the right-side panel, like app navigation.

2. Workflow control

If you enter 10, the first button runs --limit 10. The classification button classifies all uncategorized strategy objects in proofs #1–#10 and writes each result into that strategy's category field.

3. Notes

Overview enumerates items in the selected dataset. Processed/matched items are green.

RealAnalysis reads data/processed/proofs_with_key_strategies.jsonl. HighDimensionalStatistics reads data/high_dimensional_statistics/processed/proofs_with_key_strategies.jsonl.
