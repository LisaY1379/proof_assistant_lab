2. Workflow control

If you enter 10, the first button runs --limit 10. The classification button classifies all uncategorized strategy objects in proofs #1–#10 and writes each result into that strategy's category field.

3. Notes

Overview enumerates all theorem/lemma items. Processed items are green.

Processed proofs are read from data/processed/proofs_with_key_strategies.jsonl.
