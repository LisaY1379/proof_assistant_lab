FROM MANY POSSIBILITIES TO ONE EXACT COUNT

Count possibilities.
Without trying them all.

Suppose you are configuring a system with many yes-or-no choices and rules about which choices can coexist. Checking one configuration is easy; searching all combinations doubles the work with every new choice. Must that exponential growth persist even with a clever algorithm? This paper presents a deterministic way to count every valid configuration for fixed-width SAT with a sublinear exponent. It reorganizes the count into local calculations linked by small shared summaries, then recovers the exact answer algebraically.

THE QUESTION, THE OBSTACLE & THE IDEAIntroduction

01 / WHAT PEOPLE WANT TO DO

Find a valid choice without searching forever.

Rules in planning, circuit design and configuration can be written in terms of switches that are either true or false. A literal is a switch or its negation; a clause says at least one of several literals must hold. A formula in k-CNF asks that every clause hold, with at most k literals in each clause. In this paper, k is fixed as the number of variables grows.

SAT asks whether at least one configuration works. #SAT asks how many work. The second question answers the first: a positive count means there is a solution.

\[F=(x_1\lor x_2)\land(x_3\lor x_4)\land(x_2\lor x_3)\]

Here ∨ means “or,” ∧ means “and,” and xᵢ is either 0 or 1. Our example has 16 possible configurations and 8 valid ones.

02 / WHY THE RESULT MATTERS

A smaller exponent changes the expectation.

The Exponential Time Hypothesis predicts that some 3-SAT inputs require time with an exponent proportional to the number of variables, even for the best deterministic algorithm. Earlier improvements lowered the constant in that exponent. The paper’s result instead makes the exponent grow more slowly than n.

That matters because ETH has been used to explain why many other algorithmic problems resist speedups. A refutation removes that particular foundation for those conditional lower bounds. It does not automatically provide a fast replacement algorithm for every problem that used the hypothesis.

FIXED EXPONENTIAL RATE
\(2^{cn},\quad c>0\)

The exponent per variable stays at c.

SUBEXPONENTIAL RATE
\(2^{o(n)}\)

The exponent divided by n tends to zero.

Subexponential still can be enormous. The statement is an asymptotic guarantee; it neither proves P = NP nor reports measured SAT-solver performance.

03 / THE CENTRAL OBSTACLE

Splitting the variables is easy. Splitting their dependencies is not.

If no rule crossed between groups, we could count valid choices within each group and multiply. But a rule like x₂ ∨ x₃ connects our left and right groups. Ignoring that bridge counts the invalid configuration (1,0,0,1), giving 9 instead of 8.

The paper’s idea is to make each group share a small summary of its bits. Once all summaries are fixed, the remaining calculations separate. In the example below, the shared bits are simply x₂ and x₃. The paper builds more subtle bounded integer measurements after changing the polynomial inputs.

04 / HOW THE PIECES FIT

Move to easier inputs. Recover the original answer.

Sharing every boundary bit could still be expensive. The construction therefore changes the inputs of the clause polynomials using a parameter T. At T = 0 the original inputs return; at selected other points, local groups interact only through a few summaries.

The resulting total H(T) is a polynomial. Instead of evaluating H(0) by exhaustive search, the algorithm computes enough values and Taylor coefficients at the easier points to reconstruct it exactly. The difficult balance is to keep both the summaries and the polynomial degree small.

For general SAT, sparse parity tests compress many clause checks while retaining every genuine solution. The common-zero counter then chooses extra tests that eliminate all remaining false positives.

Declared Boolean variables, input clauses, and fixed maximum clause width. Free variables remain part of the count.
Q, R, r
Number of nonzero interpolation points, degree bound on replacement forms, and number of variable groups. R/Q must be small.
C, D, τ
C denotes measurement matrices, each integer row has ℓ₁ norm at most D, and the total row count is at most 2τn. In the headline density assumption m≤Dn, D is a separate fixed density constant.
